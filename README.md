# Zen Companion

Небольшое приложение для macOS, которое устанавливает оформление и функциональные улучшения поверх официального Zen Browser. Это не форк браузера и не официальный проект команды Zen.

## Возможности

- Общий переключатель улучшений и один регулятор прозрачности.
- Два режима: «Стекло» и «Универсальное». Оба следуют светлой/тёмной теме macOS.
- Универсальный режим приглушает цвета сайта под интерфейсом и использует нейтральные согласованные подложки. Оформление сайтов не меняется.
- Оформление боковой панели, поиска, миниплееров, PiP и других элементов интерфейса.
- Авто-PiP, управление курсором плеера и перевод через контекстное меню.
- Применение прозрачности и переключателя без перезапуска после первоначальной установки.
- Резервная копия перед установкой, восстановление и удаление через меню обслуживания.
- Восстановление загрузчика после обновления Zen, только для проверенной версии и сборки.
- Неизвестная сборка блокируется; приложение сообщает о конфликте. Наличие API проверяется дополнительно, но не заменяет реальную проверку поведения браузера.
- Обновления приложения с GitHub проверяются по Ed25519-подписи и SHA-256. Закрытый ключ в репозитории отсутствует.

## Установка

Скачайте `Zen-Companion-macOS-arm64.zip` из [Releases](https://github.com/Zhigalove/zen-companion/releases), распакуйте и переместите **Zen Companion.app** в «Программы». Откройте приложение и нажмите «Установить улучшения». После первоначальной установки полностью закройте Zen через **⌘Q** и откройте снова.

Для текущего пользователя значение прозрачности из старого мода подхватывается автоматически. Настройка внутри Zen Mods заменяется управлением из приложения. История, пароли, cookies и вкладки не импортируются и не изменяются.

Для записи загрузчика внутрь Zen.app macOS может потребовать разрешение **Конфиденциальность и безопасность → Управление приложениями → Zen Companion**. Приложение сообщает об отказе и открывает нужный раздел, но само разрешение не включает. После обновления ad-hoc сборки разрешение может понадобиться повторно.

Первая версия: Apple Silicon, macOS 14+. Поддерживаемые сборки Zen перечислены в `Resources/compatibility.json`; первоначально проверен Zen 1.23.4b, build 20261020090730. Изменение списка проверенных версий требует новой подписанной публикации; он не расширяется автоматически по совпадению номера Gecko.

**Подпись macOS:** сборки распространяются с ad-hoc подписью. Developer ID и нотариализация Apple не планируются; необходимые разрешения macOS владелец выдаёт вручную. На другом Mac Gatekeeper может потребовать отдельного разрешения владельца. Приложение не отключает системную защиту. Цифровая подпись метаданных обновления — отдельный механизм и не заменяет нотариализацию Apple.

## Что изменяется

CSS и JavaScript устанавливаются в выбранный профиль Zen. Два файла загрузчика находятся внутри `Zen.app`; это меняет ресурсы официального подписанного приложения. Бинарники Zen не заменяются, приложение Zen не переподписывается. Изменённые ресурсы могут нарушать проверку исходной подписи Zen.

Проверка обновления запускается пользовательским LaunchAgent раз в 30 секунд и завершается. Она не читает страницы, не отправляет телеметрию и не держит постоянный процесс. На неподтверждённой версии помощник ничего не восстанавливает. Если старый загрузчик сохранился, мост настроек отключает доработки до загрузки функциональных модулей.

Папка приложения: `~/Library/Application Support/Zen Companion/`. Настройки профиля: `ultimate-glass-settings.json`. Старые технические идентификаторы сохранены, чтобы обновить существующую установку без дублирования. Резервные копии находятся только на компьютере, максимум 10 последних копий установки. Они содержат настройки и файлы улучшений, не полную резервную копию профиля.

После обновления Zen или самого компаньона для загрузки новых JS/CSS-файлов может потребоваться полный перезапуск Zen. Приложение показывает это отдельно от применения ползунка прозрачности.

## Сборка

Нужны Xcode Command Line Tools. Python требуется только для тестов, не для работы приложения.

```sh
./build.sh
python3 Tests/backend_test.py
node Tests/settings_test.mjs
```

Готовое приложение: `build/Zen Companion.app`. Архитектура по умолчанию arm64; для сборки тестов на Intel можно задать `ZEN_COMPANION_ARCH=x86_64`.

Тесты установщика работают в отдельной временной папке с фиктивным приложением Zen. Проверяют перенос настроек, сохранение посторонних файлов, блокировку неизвестной версии и чужого загрузчика, восстановление и удаление. Проверки реального плеера, Space, визуала и связи с работающим Zen выполняются отдельно; CI их не имитирует.

## Публикация обновления

1. Проверить совместимость с конкретной сборкой Zen и обновить `Resources/compatibility.json`.
2. Поднять `appVersion`, собрать приложение и проверить его.
3. Упаковать `.app` и подписать `update.json` отдельным закрытым Ed25519-ключом с помощью `Tools/Release.swift`.
4. Опубликовать архив и `update.json` в GitHub Release с тегом `v<appVersion>`.

Закрытый ключ не должен попадать в исходники, архив, логи CI или публичные артефакты. CI собирает приложение и запускает изолированные тесты, но не имеет ключа публикации и не одобряет новые версии Zen сам.
